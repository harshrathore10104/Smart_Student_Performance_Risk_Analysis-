# Design Decisions & Rationale

1. **Python** was selected because the project requires data processing, visualization, machine learning, and report generation.
2. **Streamlit** provides a lightweight interface without requiring a separate frontend framework.
3. **SQLite** is suitable for a self-contained college project and avoids external database configuration.
4. **Random Forest** provides a straightforward supervised classification model and can handle mixed academic features.
5. **Plotly** provides interactive charts for dashboard analysis.
6. **ReportLab** creates portable PDF reports.
7. The code is divided into modules to improve maintainability and testing.
